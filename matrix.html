Assembly Instruction Execution Flow
  • 1. MOV AL, ROW & MUL BL -> Compute Row Offset (i × 3)
  • 2. LEA BX, MATRIX & ADD BX, AX -> Base Reg BX = Start of Row i
  • 3. MOV SI, COL -> Index Reg SI = Column Offset (j)
  • 4. MOV AL, [BX + SI] -> Fetch Element using Based-Indexed EA
  • 5. MOV RESULT, AL -> Store to memory variable & complete
